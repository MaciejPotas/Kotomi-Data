# Grammar profile isolation

Paczka Grammar zachowuje teraz osobny profil każdego kontrolera. Otwarcie kolejnego quizu nie zmienia ustawień ani rozwinięć poprzedniego. To publikacja kodu paczki; słowniki i XML lekcji pozostają bez zmian. Opis solvera, podglądu i testów syntetycznych jest w audycie silnika konstrukcji w repozytorium Kotomi.
